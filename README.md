# 便利ツールまとめ

GitHub Pagesでそのまま公開できる、HTML/CSS/JavaScriptのみの静的な便利ツール集です。身内向けの簡単な作業を、ブラウザ内だけで完結できるようにしています。

## ツール

- 立替精算: 名前と支払済み金額から、合計、1人あたりの負担額、精算先を表示します。
- ランダム抽選: 改行区切りの候補から、重複なしで指定人数を抽選します。
- ランダム番号振り分け: 候補をランダム順に並べ、開始番号から番号を割り当てます。
- ルーレット: 通常モードと、選ばれた人を除外する指名モードがあります。
- URL共有用QRコード生成: URLからQRコードをブラウザ内で生成し、PNG画像として保存できます。

## プライバシー

- 入力内容はサーバーへ送信しません。
- 入力内容は保存しません。
- ブラウザの永続保存機能は使用していません。
- 外部APIや外部配信サービスには依存していません。
- 各ツールの処理はブラウザ内だけで完了します。

## 使い方

`index.html` をブラウザで開くと利用できます。GitHub Pagesでも追加設定なしで動作します。

## GitHub Pagesで公開する方法

1. このフォルダのファイルをGitHubリポジトリへ配置します。
2. GitHubのリポジトリ画面で `Settings` を開きます。
3. `Pages` を開きます。
4. `Source` で `Deploy from a branch` を選択します。
5. `Branch` で `main`、フォルダで `/root` を選択します。
6. 保存後、表示されたURLへアクセスします。

## 公開後の確認方法

公開後は、GitHub PagesのURLで以下を確認してください。

- トップページに5つのツールカードが表示されること。
- 各ツールへページ内移動できること。
- 立替精算、抽選、番号振り分け、ルーレット、QRコード生成が動作すること。
- スマホ幅で横スクロールが出ず、入力欄とボタンが押しやすいこと。
- QRコード生成時も外部APIへアクセスしていないこと。

公開URLは通常、次の形式です。

```text
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

ユーザー名と同じ名前の特別なリポジトリで公開する場合は、次の形式になることがあります。

```text
https://<GitHubユーザー名>.github.io/
```

## ファイル構成

- `index.html`: 画面構成
- `styles.css`: 表示スタイル
- `script.js`: 各ツールの処理
